# 学术排版规范

## 使用时机与优先级

在逐页规划之前读取，固定全篇字体与主题。用户明确指定的主题参考优先；仅借鉴布局的图片不自动成为主题或母版。无主题参考时采用下列默认值。按referenceUse决定布局是否锁定：严格复现/局部编辑保留原结构，结构借鉴与新建则逐页选构图。

## 页面与区域

以1280×720逻辑像素为画布，比例16:9；坐标原点在左上角。

| 区域 | 默认范围或间距 |
| --- | --- |
| 水平安全边距 | 左右48 px |
| 页标题区 | x=48，y=28，w=1184，h=64 |
| 标题分隔线 | y=103；装饰线不得侵入标题 |
| 总括句区 | x=48，y=116，w=1184，h=36 |
| 正文区 | x=48，y=164，w=1184，h=480 |
| 正文与页脚缓冲区 | y=652—676，保持留白，不设置来源或出处小字 |
| 页脚 | 分隔线y=681；页码位于右下角 |
| 模块间距 | 默认16 px；三列布局使用16 px列间距 |
| 模块内边距 | 默认20—24 px，同构模块取同值 |

上下总括是可选构图：上方解释关键关系，下方归纳证据所得，两句不重复；不需要时可省略一句或两句，释放面积给主体。使用时统一为26 px粗体，但不要求所有页都出现。正文可按本页逻辑采用横向流程、分支图、三列对比、中心辐射、证据图或矩阵。固定文字角色不等于固定构图。

## 文字角色与固定字号

默认字体Microsoft YaHei，拉丁字母与数字沿用同一字体。生成前核实字体可用；缺失时选择可用字体并全篇统一替换，不能任由局部回退。

下表px为96 DPI逻辑像素，pt为PowerPoint字号；1 px=0.75 pt，调用不同API时明确单位。

| 角色 | px | pt | 默认字重 |
| --- | --- | --- | --- |
| 页标题 | 42 | 31.5 | 粗体 |
| 上方主旨／下方结论 | 26 | 19.5 | 粗体 |
| 模块标题 | 26 | 19.5 | 粗体 |
| 正文／图内节点标签 | 23 | 17.25 | 正常；节点标签可统一粗体 |
| 必要图片说明 | 23 | 17.25 | 正常，与正文一致；默认不新增 |
| 页码 | 14 | 10.5 | 正常 |

同角色全篇字号一致；同构模块同时保持字重、对齐、文本框尺寸、内边距和段落间距一致。正文统一左对齐，短节点标签可居中。可设置独立的“中心主体”角色（32 px）和“指标数字”角色（40 px），但应在规划中登记并跨页复用，不能用新增角色规避字号一致要求。正文默认行距1.15倍；同级条目段后距统一。

论文图片中原有文字不冒充可编辑正文；检查其投影阅读尺寸。可编辑图表的坐标、图例也需统一角色。公式使用支持数学符号的字体并保持同类公式一致。

## 页面不显示出处小字

页面上不添加“来源：……”“出自……”“资料来源”“图片来源”“参考文献”等出处说明，不添加用于溯源的网址、DOI、引用编号或作者年份脚注。也不将这些信息改成“依据：……”“参考：……”放进图注或页脚。完整出处只写入演讲者备注和任务内的sources／materials记录，不自动另加参考文献页。

默认不新增图片下方小字、“示例：……”说明、装饰性英文副标题或模板编号。图意已经由模块标题说明时不重复描述。确有必要的限定信息并入正常字号正文。方法名称、模型名称、实验年份、坐标单位、图例和必要限定条件仍作为内容保留。需要说明概念或假设性质时，在正常标题或正文中写明“概念示意”“拟议方案”，不增设细小的制作说明。

## 配色与视觉材料

- 无模板时白色背景；可编辑文字只使用深蓝#163D6B、黑色#111111、暗红#A61B29。取消灰色、青色、浅蓝色次要文字。
- 图形边框深蓝，浅底#EFF4FB。默认浅底配深色文字；只有模板规定的实色标题条才用白字等反白文字。
- 有明确主题参考时按其角色保留颜色，包括标题条和反白文字；仅借鉴结构时沿用全篇主题，不继承截图全部配色。将允许颜色写入template-contract，区分可编辑文字和原始证据图片。
- 暗红只强调关键差异、问题或边界，不给平级模块随意分配不同文字色。
- 图表中同一方法、数据集或实验组跨页使用同色，辅以标签或线型区分。
- 图片、图表优先解释场景、方法和结果；不以装饰图片挤占证据图的阅读面积。
- 不用大面积渐变、阴影、立体效果替代信息层级。用户指定的参考效果可保留。

## 分区、层次与连接

先确定整页分区和内容对应关系。流程可用节点框和定向箭头；包含关系可用共同外框；比较可用对齐列或矩阵；时序可用时间标记。不把并列画成因果。图片与相关说明靠近或同组；同构模块的内边距与基线一致，不同页的栏宽和标题条数量可变。框线表达实际关系，不给每句话套框，也不要求照片必须在大面板内。

## 溢出处理顺序

1. 检查文本框内边距、显式换行和错误的段落设置。
2. 删除重复表达并精炼句子；保留专名、否定条件、年份、单位、实验设置及结论边界。
3. 调整模块宽高、图文占比或选择更合适的整页布局；同构模块同步调整。
4. 页数允许时按逻辑拆页，并更新逐页规划；用户限定一页时先重组信息，不擅自增加页数。
5. 如仍不能容纳，说明具体冲突。不得自动缩小某一个文本框、启用缩字适应或静默删除必需内容。

用户明确要求变更字号体系时，统一调整全篇对应角色，并重新检查所有页面。

## 与现有生成器的衔接

这是生成与审查规范，不是已实现的自动样式引擎。部分现有组件仍有硬编码字号，并非全部符合上述角色表；brief.json目前不能传入完整字号体系。调用前核对所选组件，必要时在任务内使用可配置的生成适配代码统一角色，再渲染验证，不为一次任务直接修改共享组件。无法做到时说明限制，不将旧组件输出宣称为符合academic-v1。

字号、区域和对齐检查应与实际渲染结合；仅通过字符数量检查不能证明排版合格。
