# 三列图文

## 使用条件

固定3列，每列3项举措；可插入本地照片或使用原生节点示意图。

## 输入容量

列标题最多9字，横条标题12字，每条举措14字。图片需来源与图注。

## 调用

在 examples/samples.json 的第 3、4 个案例基础上换内容，通过 scripts/build.mjs 构建。生成器位于 scripts/components/index.mjs。

## 检查

核对关系、文字完整性、对象可编辑性、图片来源，再渲染检查。超出当前固定结构时应选其他组件，不能静默截断数据。
