# 三级梯形层级

## 使用条件

固定3级，上到下输入。必须有层级依据，不表示数值面积。

## 输入容量

层级标题最多14字，说明36字，关键词7字。

## 调用

在 examples/samples.json 的第 5、6 个案例基础上换内容，通过 scripts/build.mjs 构建。生成器位于 scripts/components/index.mjs。

## 检查

核对关系、文字完整性、对象可编辑性、图片来源，再渲染检查。超出当前固定结构时应选其他组件，不能静默截断数据。
