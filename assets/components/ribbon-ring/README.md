# 四瓣折带圆环

## 使用条件

固定1个中心与4个并列方向，不表达时序；方向标签沿弧逐字排布。

## 输入容量

中心最多14字，方向最多10字，说明最多36字。推荐显式换行中心与说明。

## 调用

在 examples/samples.json 的第 1、2 个案例基础上换内容，通过 scripts/build.mjs 构建。生成器位于 scripts/components/index.mjs。

## 检查

核对关系、文字完整性、对象可编辑性、图片来源，再渲染检查。超出当前固定结构时应选其他组件，不能静默截断数据。
